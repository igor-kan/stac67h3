Derivation of the normal equations, the projection hat matrix, and the Gauss-Markov theorem.

1. The General Linear Model

We express the multiple linear regression model for \(n\) observations and \(p-1\) predictors in matrix notation: \[\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}\] where: * \(\mathbf{y} \in \mathbb{R}^{n \times 1}\) is the response vector. * \(\mathbf{X} \in \mathbb{R}^{n \times p}\) is the design matrix (with a first column of ones for the intercept). * \(\boldsymbol{\beta} \in \mathbb{R}^{p \times 1}\) is the vector of unknown regression coefficients. * \(\boldsymbol{\varepsilon} \in \mathbb{R}^{n \times 1}\) is the random error vector satisfying: \[\mathbb{E}[\boldsymbol{\varepsilon}] = \mathbf{0}, \qquad \operatorname{Var}(\boldsymbol{\varepsilon}) = \sigma^2 \mathbf{I}_n\]

2. Ordinary Least Squares (OLS) Estimator

We seek \(\hat{\boldsymbol{\beta}}\) that minimizes the residual sum of squares (SSE): \[Q(\boldsymbol{\beta}) = \boldsymbol{\varepsilon}^T \boldsymbol{\varepsilon} = (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^T (\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) = \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\beta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}\]

Taking the vector derivative with respect to \(\boldsymbol{\beta}\) and equating to zero: \[\frac{\partial Q}{\partial \boldsymbol{\beta}} = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{0}\]

This yields the Normal Equations: \[\mathbf{X}^T\mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}^T\mathbf{y}\]

Assuming \(\mathbf{X}\) has full column rank (\(\operatorname{rank}(\mathbf{X}) = p\)), the matrix \(\mathbf{X}^T\mathbf{X}\) is strictly invertible: \[\boxed{\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}}\]

Sampling Distribution & Unbiasedness

  1. Expectation: \[\mathbb{E}[\hat{\boldsymbol{\beta}}] = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \mathbb{E}[\mathbf{y}] = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T (\mathbf{X}\boldsymbol{\beta}) = \boldsymbol{\beta} \quad (\text{Unbiased})\]
  2. Variance-Covariance Matrix: \[\operatorname{Var}(\hat{\boldsymbol{\beta}}) = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \operatorname{Var}(\mathbf{y}) \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1} = \sigma^2 (\mathbf{X}^T\mathbf{X})^{-1}\]

3. The Hat Matrix (Orthogonal Projection)

The fitted values are: \[\hat{\mathbf{y}} = \mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} = \mathbf{H}\mathbf{y}\] where \(\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\) is the Hat Matrix.

Key Algebraic Properties of \(\mathbf{H}\):

  1. Symmetric: \(\mathbf{H}^T = \mathbf{H}\).
  2. Idempotent: \(\mathbf{H}^2 = \mathbf{H}\) (projecting twice is the same as projecting once).
  3. Trace: \(\operatorname{tr}(\mathbf{H}) = \operatorname{tr}(\mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T) = \operatorname{tr}((\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{X}) = \operatorname{tr}(\mathbf{I}_p) = p\).
  4. Residual Vector: \(\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}} = (\mathbf{I} - \mathbf{H})\mathbf{y}\). Because \(\mathbf{X}^T(\mathbf{I} - \mathbf{H}) = \mathbf{0}\), the residual vector is strictly orthogonal to the column space of \(\mathbf{X}\) (\(\mathbf{X}^T\mathbf{e} = \mathbf{0}\)).

4. Quadratic Forms in Regression Analysis

In statistical theory, sums of squares (SSTO, SSR, SSE) are not merely algebraic sums of squared scalars—they are quadratic forms of the random response vector \(\mathbf{y} \in \mathbb{R}^n\).

NoteDefinition: Quadratic Form

Let \(\mathbf{y} \in \mathbb{R}^n\) and let \(\mathbf{A} \in \mathbb{R}^{n \times n}\) be a real symmetric matrix (\(\mathbf{A} = \mathbf{A}^T\)). The scalar function: \[Q(\mathbf{y}) = \mathbf{y}^T \mathbf{A} \mathbf{y} = \sum_{i=1}^n \sum_{j=1}^n A_{ij} y_i y_j\] is the quadratic form associated with matrix \(\mathbf{A}\).

4.1 Representation of Regression Sums of Squares

Let \(\mathbf{J}_n = \mathbf{1}_n \mathbf{1}_n^T\) denote the \(n \times n\) matrix of all ones, and let \(\left(\frac{1}{n} \mathbf{J}_n\right)\) be the centering projection matrix. The total, model, and residual sums of squares can be written explicitly as quadratic forms:

  1. Total Sum of Squares (SSTO): \[\text{SSTO} = \sum_{i=1}^n (y_i - \bar{y})^2 = \mathbf{y}^T \left(\mathbf{I}_n - \frac{1}{n}\mathbf{J}_n\right) \mathbf{y} = \mathbf{y}^T \mathbf{A}_{\text{TO}} \mathbf{y}\] where \(\mathbf{A}_{\text{TO}} = \mathbf{I}_n - \frac{1}{n}\mathbf{J}_n\) is symmetric and idempotent of rank \(n - 1\).

  2. Residual / Error Sum of Squares (SSE): \[\text{SSE} = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \mathbf{e}^T \mathbf{e} = [(\mathbf{I} - \mathbf{H})\mathbf{y}]^T [(\mathbf{I} - \mathbf{H})\mathbf{y}] = \mathbf{y}^T (\mathbf{I} - \mathbf{H}) \mathbf{y} = \mathbf{y}^T \mathbf{A}_{\text{E}} \mathbf{y}\] where \(\mathbf{A}_{\text{E}} = \mathbf{I} - \mathbf{H}\) is symmetric and idempotent with rank \(\operatorname{tr}(\mathbf{I} - \mathbf{H}) = n - p\).

  3. Regression / Model Sum of Squares (SSR): \[\text{SSR} = \sum_{i=1}^n (\hat{y}_i - \bar{y})^2 = \mathbf{y}^T \left(\mathbf{H} - \frac{1}{n}\mathbf{J}_n\right) \mathbf{y} = \mathbf{y}^T \mathbf{A}_{\text{R}} \mathbf{y}\] where \(\mathbf{A}_{\text{R}} = \mathbf{H} - \frac{1}{n}\mathbf{J}_n\) is symmetric and idempotent with rank \(\operatorname{tr}(\mathbf{H}) - \operatorname{tr}(\frac{1}{n}\mathbf{J}) = p - 1\).

The fundamental ANOVA decomposition is therefore an identity of symmetric matrices: \[\mathbf{A}_{\text{TO}} = \mathbf{A}_{\text{R}} + \mathbf{A}_{\text{E}} \iff \left(\mathbf{I} - \frac{1}{n}\mathbf{J}\right) = \left(\mathbf{H} - \frac{1}{n}\mathbf{J}\right) + (\mathbf{I} - \mathbf{H})\]

5. Statistical Properties of Quadratic Forms: Craig’s and Cochran’s Theorems

5.1 Expectation of a General Quadratic Form

NoteTheorem: Mean of a Quadratic Form

Let \(\mathbf{y} \in \mathbb{R}^n\) have mean vector \(\boldsymbol{\mu} = \mathbb{E}[\mathbf{y}]\) and covariance matrix \(\boldsymbol{\Sigma} = \operatorname{Var}(\mathbf{y})\). For any symmetric matrix \(\mathbf{A} \in \mathbb{R}^{n \times n}\): \[\mathbb{E}[\mathbf{y}^T \mathbf{A} \mathbf{y}] = \operatorname{tr}(\mathbf{A} \boldsymbol{\Sigma}) + \boldsymbol{\mu}^T \mathbf{A} \boldsymbol{\mu}\]

Proof:

Since \(\mathbf{y}^T \mathbf{A} \mathbf{y}\) is a scalar, it equals its trace: \[\mathbb{E}[\mathbf{y}^T \mathbf{A} \mathbf{y}] = \mathbb{E}[\operatorname{tr}(\mathbf{y}^T \mathbf{A} \mathbf{y})] = \mathbb{E}[\operatorname{tr}(\mathbf{A} \mathbf{y} \mathbf{y}^T)] = \operatorname{tr}(\mathbf{A} \mathbb{E}[\mathbf{y} \mathbf{y}^T])\] Using \(\mathbb{E}[\mathbf{y} \mathbf{y}^T] = \boldsymbol{\Sigma} + \boldsymbol{\mu} \boldsymbol{\mu}^T\): \[\mathbb{E}[\mathbf{y}^T \mathbf{A} \mathbf{y}] = \operatorname{tr}(\mathbf{A} \boldsymbol{\Sigma}) + \operatorname{tr}(\mathbf{A} \boldsymbol{\mu} \boldsymbol{\mu}^T) = \operatorname{tr}(\mathbf{A} \boldsymbol{\Sigma}) + \boldsymbol{\mu}^T \mathbf{A} \boldsymbol{\mu} \quad \blacksquare\]

Unbiasedness of the Residual Variance Estimator \(s^2\):

For the residual sum of squares \(\text{SSE} = \mathbf{y}^T (\mathbf{I} - \mathbf{H}) \mathbf{y}\), where \(\boldsymbol{\Sigma} = \sigma^2 \mathbf{I}\) and \(\boldsymbol{\mu} = \mathbf{X}\boldsymbol{\beta}\): 1. \(\operatorname{tr}((\mathbf{I} - \mathbf{H})\sigma^2 \mathbf{I}) = \sigma^2 \operatorname{tr}(\mathbf{I} - \mathbf{H}) = \sigma^2 (n - p)\). 2. \(\boldsymbol{\mu}^T (\mathbf{I} - \mathbf{H}) \boldsymbol{\mu} = (\mathbf{X}\boldsymbol{\beta})^T (\mathbf{I} - \mathbf{H}) (\mathbf{X}\boldsymbol{\beta}) = \boldsymbol{\beta}^T \mathbf{X}^T (\mathbf{I} - \mathbf{H}) \mathbf{X} \boldsymbol{\beta} = \mathbf{0}\), since \((\mathbf{I} - \mathbf{H})\mathbf{X} = \mathbf{0}\).

Therefore: \[\mathbb{E}[\text{SSE}] = (n - p)\sigma^2 \implies \mathbb{E}\left[\frac{\text{SSE}}{n - p}\right] = \sigma^2\] proving that the mean squared error \(MSE = s^2 = \frac{\text{SSE}}{n - p}\) is an unbiased estimator of \(\sigma^2\).

5.2 Craig’s Theorem and the Independence of SSR and SSE

The construction of the ANOVA \(F\)-test requires showing that SSR and SSE are statistically independent random variables.

ImportantCraig’s Theorem

Let \(\mathbf{y} \sim \mathcal{N}_n(\boldsymbol{\mu}, \sigma^2 \mathbf{I})\). Two quadratic forms \(Q_1 = \mathbf{y}^T \mathbf{A} \mathbf{y}\) and \(Q_2 = \mathbf{y}^T \mathbf{B} \mathbf{y}\) (where \(\mathbf{A}, \mathbf{B}\) are real symmetric) are statistically independent if and only if: \[\mathbf{A} \mathbf{B} = \mathbf{0}\]

Proof that SSR and SSE are Independent:

Recall \(\mathbf{A}_{\text{R}} = \mathbf{H} - \frac{1}{n}\mathbf{J}\) and \(\mathbf{A}_{\text{E}} = \mathbf{I} - \mathbf{H}\). We compute their matrix product: \[\mathbf{A}_{\text{R}} \mathbf{A}_{\text{E}} = \left(\mathbf{H} - \frac{1}{n}\mathbf{J}\right)(\mathbf{I} - \mathbf{H}) = \mathbf{H}(\mathbf{I} - \mathbf{H}) - \frac{1}{n}\mathbf{J}(\mathbf{I} - \mathbf{H})\]

  1. Since \(\mathbf{H}\) is idempotent (\(\mathbf{H}^2 = \mathbf{H}\)): \[\mathbf{H}(\mathbf{I} - \mathbf{H}) = \mathbf{H} - \mathbf{H}^2 = \mathbf{H} - \mathbf{H} = \mathbf{0}\]
  2. For any regression model with an intercept, the column of ones \(\mathbf{1}\) is in the column space of \(\mathbf{X}\) (\(\mathbf{X} = [\mathbf{1} \mid \mathbf{X}_1]\)), meaning \(\mathbf{H}\mathbf{1} = \mathbf{1}\). Because \(\mathbf{J} = \mathbf{1}\mathbf{1}^T\): \[\mathbf{J}\mathbf{H} = (\mathbf{1}\mathbf{1}^T)\mathbf{H} = \mathbf{1}(\mathbf{H}\mathbf{1})^T = \mathbf{1}\mathbf{1}^T = \mathbf{J} \implies \mathbf{J}(\mathbf{I} - \mathbf{H}) = \mathbf{J} - \mathbf{J}\mathbf{H} = \mathbf{0}\]

Combining both parts: \[\mathbf{A}_{\text{R}} \mathbf{A}_{\text{E}} = \mathbf{0} - \mathbf{0} = \mathbf{0}\]

By Craig’s Theorem, \(\text{SSR}\) and \(\text{SSE}\) are strictly independent random variables. Consequently, the test statistic: \[F^* = \frac{\text{SSR} / (p - 1)}{\text{SSE} / (n - p)} \sim F(p - 1, n - p)\] is a ratio of independent chi-square variables, rigorously establishing the validity of the overall regression \(F\)-test.

6. Positive Definiteness, Gramian Matrices, and Cholesky Factorization

6.1 The Positive Definiteness of the Gram Matrix \(\mathbf{X}^T \mathbf{X}\)

In multiple regression, the cross-product matrix \(\mathbf{X}^T \mathbf{X} \in \mathbb{R}^{p \times p}\) is the Gram matrix of the predictor column vectors.

NoteTheorem: Definiteness of \(\mathbf{X}^T \mathbf{X}\)
  1. For any real matrix \(\mathbf{X} \in \mathbb{R}^{n \times p}\), the Gram matrix \(\mathbf{X}^T \mathbf{X}\) is positive semidefinite (\(\mathbf{X}^T \mathbf{X} \succeq 0\)).
  2. If \(\mathbf{X}\) has full column rank (\(\operatorname{rank}(\mathbf{X}) = p \le n\)), then \(\mathbf{X}^T \mathbf{X}\) is strictly positive definite (\(\mathbf{X}^T \mathbf{X} \succ 0\)).

Proof:

For any arbitrary non-zero vector \(\mathbf{v} \in \mathbb{R}^p\), consider the quadratic form: \[\mathbf{v}^T (\mathbf{X}^T \mathbf{X}) \mathbf{v} = (\mathbf{X}\mathbf{v})^T (\mathbf{X}\mathbf{v}) = \|\mathbf{X}\mathbf{v}\|_2^2 \ge 0\] Since the Euclidean norm is non-negative, \(\mathbf{X}^T \mathbf{X} \succeq 0\).

If \(\operatorname{rank}(\mathbf{X}) = p\), the columns of \(\mathbf{X}\) are linearly independent, meaning the null space contains only the zero vector: \[\mathbf{X}\mathbf{v} = \mathbf{0} \iff \mathbf{v} = \mathbf{0}\] Thus, for all \(\mathbf{v} \neq \mathbf{0}\), \(\|\mathbf{X}\mathbf{v}\|_2^2 > 0\). Hence \(\mathbf{v}^T (\mathbf{X}^T \mathbf{X}) \mathbf{v} > 0\), establishing that \(\mathbf{X}^T \mathbf{X}\) is strictly positive definite (\(\mathbf{X}^T \mathbf{X} \succ 0\)). \(\blacksquare\)

6.2 Numerical Solution of the Normal Equations via Cholesky Factorization

In computational statistics, explicitly inverting the \(p \times p\) matrix \((\mathbf{X}^T \mathbf{X})^{-1}\) is strictly avoided because direct matrix inversion is numerically unstable and computationally inefficient.

Because \(\mathbf{X}^T \mathbf{X} \succ 0\), it admits a unique Cholesky decomposition: \[\mathbf{X}^T \mathbf{X} = \mathbf{L} \mathbf{L}^T\] where \(\mathbf{L} \in \mathbb{R}^{p \times p}\) is a lower triangular matrix with strictly positive diagonal elements (\(L_{ii} > 0\)).

The normal equations \(\mathbf{X}^T \mathbf{X} \hat{\boldsymbol{\beta}} = \mathbf{X}^T \mathbf{y}\) are solved in two linear triangular stages: 1. Forward Substitution: Solve \(\mathbf{L} \mathbf{z} = \mathbf{X}^T \mathbf{y}\) for \(\mathbf{z} \in \mathbb{R}^p\) (\(O(p^2)\) operations). 2. Back Substitution: Solve \(\mathbf{L}^T \hat{\boldsymbol{\beta}} = \mathbf{z}\) for \(\hat{\boldsymbol{\beta}} \in \mathbb{R}^p\) (\(O(p^2)\) operations).

This reduces the computational cost to \(\frac{1}{3} p^3\) operations—half the cost of general LU decomposition—with guaranteed numerical stability.

6.3 Spectral Properties of the Projection Hat Matrix \(\mathbf{H}\)

The hat matrix \(\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \in \mathbb{R}^{n \times n}\) is an orthogonal projection operator onto the \(p\)-dimensional column space \(\operatorname{Col}(\mathbf{X})\):

  1. Eigenvalues of \(\mathbf{H}\): Let \(\lambda\) be an eigenvalue of \(\mathbf{H}\) with eigenvector \(\mathbf{v} \neq \mathbf{0}\): \[\mathbf{H}\mathbf{v} = \lambda \mathbf{v} \implies \mathbf{H}^2 \mathbf{v} = \lambda \mathbf{H}\mathbf{v} = \lambda^2 \mathbf{v}\] Since \(\mathbf{H}^2 = \mathbf{H}\), we have \(\lambda^2 \mathbf{v} = \lambda \mathbf{v} \implies \lambda(\lambda - 1)\mathbf{v} = \mathbf{0}\). Therefore, all eigenvalues of \(\mathbf{H}\) are strictly 0 or 1: \[\lambda_i(\mathbf{H}) \in \{0, 1\}\]
  2. Multiplicity of Eigenvalues: The sum of the eigenvalues equals the matrix trace: \[\sum_{i=1}^n \lambda_i = \operatorname{tr}(\mathbf{H}) = p\] Therefore, \(\mathbf{H}\) has exactly \(p\) eigenvalues equal to 1 and \(n - p\) eigenvalues equal to 0.
  3. Spectral Decomposition: \[\mathbf{H} = \mathbf{Q} \begin{pmatrix} \mathbf{I}_p & \mathbf{0} \\ \mathbf{0} & \mathbf{0}_{n-p} \end{pmatrix} \mathbf{Q}^T = \sum_{i=1}^p \mathbf{q}_i \mathbf{q}_i^T\] where \(\{\mathbf{q}_1, \dots, \mathbf{q}_p\}\) forms an orthonormal basis for \(\operatorname{Col}(\mathbf{X})\).

7. Singular Value Decomposition (SVD) and Multicollinearity

The Singular Value Decomposition of the design matrix \(\mathbf{X} \in \mathbb{R}^{n \times p}\): \[\mathbf{X} = \mathbf{U} \boldsymbol{\Sigma} \mathbf{V}^T\] provides deep insight into the stability of the normal equations: - \(\mathbf{U} \in \mathbb{R}^{n \times p}\) contains orthonormal basis vectors for \(\operatorname{Col}(\mathbf{X})\). - \(\boldsymbol{\Sigma} = \operatorname{diag}(\sigma_1, \dots, \sigma_p)\) contains singular values \(\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_p > 0\). - \(\mathbf{V} \in \mathbb{R}^{p \times p}\) is orthogonal.

The Gram matrix decomposes as: \[\mathbf{X}^T \mathbf{X} = (\mathbf{V} \boldsymbol{\Sigma} \mathbf{U}^T)(\mathbf{U} \boldsymbol{\Sigma} \mathbf{V}^T) = \mathbf{V} \boldsymbol{\Sigma}^2 \mathbf{V}^T\] and its inverse is: \[(\mathbf{X}^T \mathbf{X})^{-1} = \mathbf{V} \boldsymbol{\Sigma}^{-2} \mathbf{V}^T = \sum_{j=1}^p \frac{1}{\sigma_j^2} \mathbf{v}_j \mathbf{v}_j^T\]

The Condition Number \(\kappa(\mathbf{X}) = \frac{\sigma_1}{\sigma_p}\) governs numerical sensitivity. When severe multicollinearity exists, the smallest singular value \(\sigma_p \approx 0\), causing \(\frac{1}{\sigma_p^2} \to \infty\) and inflating the variance of \(\hat{\boldsymbol{\beta}}\) along direction \(\mathbf{v}_p\).

8. Computational Verification in Python

import numpy as np
import scipy.linalg as la

# Generate synthetic linear model data: y = X beta + epsilon
np.random.seed(42)
n, p = 100, 4
X = np.hstack([np.ones((n, 1)), np.random.randn(n, p - 1)])
true_beta = np.array([2.5, -1.8, 3.2, 0.5])
sigma_noise = 1.2
y = X @ true_beta + np.random.normal(0, sigma_noise, size=n)

# 1. Cholesky Solution of Normal Equations
XtX = X.T @ X
Xty = X.T @ y
L = np.linalg.cholesky(XtX)
z = la.solve_triangular(L, Xty, lower=True)
beta_hat = la.solve_triangular(L.T, z, lower=False)
print("Estimated Coefficients (Cholesky):\n", beta_hat)

# 2. Hat Matrix and Idempotence
H = X @ np.linalg.inv(XtX) @ X.T
assert np.allclose(H @ H, H), "Hat matrix is not idempotent!"
assert np.allclose(H, H.T), "Hat matrix is not symmetric!"

# 3. Spectral Decomposition of Hat Matrix
eigvals_H = np.linalg.eigvalsh(H)
num_ones = np.sum(np.isclose(eigvals_H, 1.0))
num_zeros = np.sum(np.isclose(eigvals_H, 0.0))
print(f"Hat Matrix Eigenvalues: {num_ones} ones (rank p={p}), {num_zeros} zeros (rank n-p={n-p})")

# 4. Craig's Theorem Verification: A_R * A_E == 0
J = np.ones((n, n))
A_R = H - (1.0 / n) * J
A_E = np.eye(n) - H
craig_product = A_R @ A_E
assert np.allclose(craig_product, 0.0), "Craig's condition violated!"
print(f"Max absolute element of A_R @ A_E: {np.max(np.abs(craig_product)):.16e} (Identically zero)")

## 1. The General Linear Model

We express the multiple linear regression model for $n$ observations and $p-1$ predictors in matrix notation:
$$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$$
where:
*   $\mathbf{y} \in \mathbb{R}^{n \times 1}$ is the response vector.
*   $\mathbf{X} \in \mathbb{R}^{n \times p}$ is the design matrix (with a first column of ones for the intercept).
*   $\boldsymbol{\beta} \in \mathbb{R}^{p \times 1}$ is the vector of unknown regression coefficients.
*   $\boldsymbol{\varepsilon} \in \mathbb{R}^{n \times 1}$ is the random error vector satisfying:
    $$\mathbb{E}[\boldsymbol{\varepsilon}] = \mathbf{0}, \qquad \operatorname{Var}(\boldsymbol{\varepsilon}) = \sigma^2 \mathbf{I}_n$$

---

## 2. Ordinary Least Squares (OLS) Estimator

We seek $\hat{\boldsymbol{\beta}}$ that minimizes the residual sum of squares (SSE):
$$Q(\boldsymbol{\beta}) = \boldsymbol{\varepsilon}^T \boldsymbol{\varepsilon} = (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^T (\mathbf{y} - \mathbf{X}\boldsymbol{\beta}) = \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\beta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$

Taking the vector derivative with respect to $\boldsymbol{\beta}$ and equating to zero:
$$\frac{\partial Q}{\partial \boldsymbol{\beta}} = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{0}$$

This yields the **Normal Equations**:
$$\mathbf{X}^T\mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}^T\mathbf{y}$$

Assuming $\mathbf{X}$ has full column rank ($\operatorname{rank}(\mathbf{X}) = p$), the matrix $\mathbf{X}^T\mathbf{X}$ is strictly invertible:
$$\boxed{\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}}$$

### Sampling Distribution & Unbiasedness
1.  **Expectation:**
    $$\mathbb{E}[\hat{\boldsymbol{\beta}}] = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \mathbb{E}[\mathbf{y}] = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T (\mathbf{X}\boldsymbol{\beta}) = \boldsymbol{\beta} \quad (\text{Unbiased})$$
2.  **Variance-Covariance Matrix:**
    $$\operatorname{Var}(\hat{\boldsymbol{\beta}}) = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \operatorname{Var}(\mathbf{y}) \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1} = \sigma^2 (\mathbf{X}^T\mathbf{X})^{-1}$$

---

## 3. The Hat Matrix (Orthogonal Projection)

The fitted values are:
$$\hat{\mathbf{y}} = \mathbf{X}\hat{\boldsymbol{\beta}} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} = \mathbf{H}\mathbf{y}$$
where $\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T$ is the **Hat Matrix**.

### Key Algebraic Properties of $\mathbf{H}$:
1.  **Symmetric:** $\mathbf{H}^T = \mathbf{H}$.
2.  **Idempotent:** $\mathbf{H}^2 = \mathbf{H}$ (projecting twice is the same as projecting once).
3.  **Trace:** $\operatorname{tr}(\mathbf{H}) = \operatorname{tr}(\mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T) = \operatorname{tr}((\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{X}) = \operatorname{tr}(\mathbf{I}_p) = p$.
4.  **Residual Vector:** $\mathbf{e} = \mathbf{y} - \hat{\mathbf{y}} = (\mathbf{I} - \mathbf{H})\mathbf{y}$. 
    Because $\mathbf{X}^T(\mathbf{I} - \mathbf{H}) = \mathbf{0}$, the residual vector is strictly orthogonal to the column space of $\mathbf{X}$ ($\mathbf{X}^T\mathbf{e} = \mathbf{0}$).

## 4. Quadratic Forms in Regression Analysis

In statistical theory, sums of squares (SSTO, SSR, SSE) are not merely algebraic sums of squared scalars—they are **quadratic forms** of the random response vector $\mathbf{y} \in \mathbb{R}^n$.

::: {.callout-note}
### Definition: Quadratic Form
Let $\mathbf{y} \in \mathbb{R}^n$ and let $\mathbf{A} \in \mathbb{R}^{n \times n}$ be a real symmetric matrix ($\mathbf{A} = \mathbf{A}^T$). The scalar function:
$$Q(\mathbf{y}) = \mathbf{y}^T \mathbf{A} \mathbf{y} = \sum_{i=1}^n \sum_{j=1}^n A_{ij} y_i y_j$$
is the **quadratic form** associated with matrix $\mathbf{A}$.
:::

### 4.1 Representation of Regression Sums of Squares

Let $\mathbf{J}_n = \mathbf{1}_n \mathbf{1}_n^T$ denote the $n \times n$ matrix of all ones, and let $\left(\frac{1}{n} \mathbf{J}_n\right)$ be the centering projection matrix. The total, model, and residual sums of squares can be written explicitly as quadratic forms:

1. **Total Sum of Squares (SSTO)**:
   $$\text{SSTO} = \sum_{i=1}^n (y_i - \bar{y})^2 = \mathbf{y}^T \left(\mathbf{I}_n - \frac{1}{n}\mathbf{J}_n\right) \mathbf{y} = \mathbf{y}^T \mathbf{A}_{\text{TO}} \mathbf{y}$$
   where $\mathbf{A}_{\text{TO}} = \mathbf{I}_n - \frac{1}{n}\mathbf{J}_n$ is symmetric and idempotent of rank $n - 1$.

2. **Residual / Error Sum of Squares (SSE)**:
   $$\text{SSE} = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = \mathbf{e}^T \mathbf{e} = [(\mathbf{I} - \mathbf{H})\mathbf{y}]^T [(\mathbf{I} - \mathbf{H})\mathbf{y}] = \mathbf{y}^T (\mathbf{I} - \mathbf{H}) \mathbf{y} = \mathbf{y}^T \mathbf{A}_{\text{E}} \mathbf{y}$$
   where $\mathbf{A}_{\text{E}} = \mathbf{I} - \mathbf{H}$ is symmetric and idempotent with rank $\operatorname{tr}(\mathbf{I} - \mathbf{H}) = n - p$.

3. **Regression / Model Sum of Squares (SSR)**:
   $$\text{SSR} = \sum_{i=1}^n (\hat{y}_i - \bar{y})^2 = \mathbf{y}^T \left(\mathbf{H} - \frac{1}{n}\mathbf{J}_n\right) \mathbf{y} = \mathbf{y}^T \mathbf{A}_{\text{R}} \mathbf{y}$$
   where $\mathbf{A}_{\text{R}} = \mathbf{H} - \frac{1}{n}\mathbf{J}_n$ is symmetric and idempotent with rank $\operatorname{tr}(\mathbf{H}) - \operatorname{tr}(\frac{1}{n}\mathbf{J}) = p - 1$.

The fundamental ANOVA decomposition is therefore an identity of symmetric matrices:
$$\mathbf{A}_{\text{TO}} = \mathbf{A}_{\text{R}} + \mathbf{A}_{\text{E}} \iff \left(\mathbf{I} - \frac{1}{n}\mathbf{J}\right) = \left(\mathbf{H} - \frac{1}{n}\mathbf{J}\right) + (\mathbf{I} - \mathbf{H})$$

## 5. Statistical Properties of Quadratic Forms: Craig's and Cochran's Theorems

### 5.1 Expectation of a General Quadratic Form

::: {.callout-note}
### Theorem: Mean of a Quadratic Form
Let $\mathbf{y} \in \mathbb{R}^n$ have mean vector $\boldsymbol{\mu} = \mathbb{E}[\mathbf{y}]$ and covariance matrix $\boldsymbol{\Sigma} = \operatorname{Var}(\mathbf{y})$. For any symmetric matrix $\mathbf{A} \in \mathbb{R}^{n \times n}$:
$$\mathbb{E}[\mathbf{y}^T \mathbf{A} \mathbf{y}] = \operatorname{tr}(\mathbf{A} \boldsymbol{\Sigma}) + \boldsymbol{\mu}^T \mathbf{A} \boldsymbol{\mu}$$
:::

#### Proof:
Since $\mathbf{y}^T \mathbf{A} \mathbf{y}$ is a scalar, it equals its trace:
$$\mathbb{E}[\mathbf{y}^T \mathbf{A} \mathbf{y}] = \mathbb{E}[\operatorname{tr}(\mathbf{y}^T \mathbf{A} \mathbf{y})] = \mathbb{E}[\operatorname{tr}(\mathbf{A} \mathbf{y} \mathbf{y}^T)] = \operatorname{tr}(\mathbf{A} \mathbb{E}[\mathbf{y} \mathbf{y}^T])$$
Using $\mathbb{E}[\mathbf{y} \mathbf{y}^T] = \boldsymbol{\Sigma} + \boldsymbol{\mu} \boldsymbol{\mu}^T$:
$$\mathbb{E}[\mathbf{y}^T \mathbf{A} \mathbf{y}] = \operatorname{tr}(\mathbf{A} \boldsymbol{\Sigma}) + \operatorname{tr}(\mathbf{A} \boldsymbol{\mu} \boldsymbol{\mu}^T) = \operatorname{tr}(\mathbf{A} \boldsymbol{\Sigma}) + \boldsymbol{\mu}^T \mathbf{A} \boldsymbol{\mu} \quad \blacksquare$$

#### Unbiasedness of the Residual Variance Estimator $s^2$:
For the residual sum of squares $\text{SSE} = \mathbf{y}^T (\mathbf{I} - \mathbf{H}) \mathbf{y}$, where $\boldsymbol{\Sigma} = \sigma^2 \mathbf{I}$ and $\boldsymbol{\mu} = \mathbf{X}\boldsymbol{\beta}$:
1. $\operatorname{tr}((\mathbf{I} - \mathbf{H})\sigma^2 \mathbf{I}) = \sigma^2 \operatorname{tr}(\mathbf{I} - \mathbf{H}) = \sigma^2 (n - p)$.
2. $\boldsymbol{\mu}^T (\mathbf{I} - \mathbf{H}) \boldsymbol{\mu} = (\mathbf{X}\boldsymbol{\beta})^T (\mathbf{I} - \mathbf{H}) (\mathbf{X}\boldsymbol{\beta}) = \boldsymbol{\beta}^T \mathbf{X}^T (\mathbf{I} - \mathbf{H}) \mathbf{X} \boldsymbol{\beta} = \mathbf{0}$, since $(\mathbf{I} - \mathbf{H})\mathbf{X} = \mathbf{0}$.

Therefore:
$$\mathbb{E}[\text{SSE}] = (n - p)\sigma^2 \implies \mathbb{E}\left[\frac{\text{SSE}}{n - p}\right] = \sigma^2$$
proving that the mean squared error $MSE = s^2 = \frac{\text{SSE}}{n - p}$ is an **unbiased estimator** of $\sigma^2$.

### 5.2 Craig's Theorem and the Independence of SSR and SSE

The construction of the ANOVA $F$-test requires showing that SSR and SSE are statistically independent random variables.

::: {.callout-important}
### Craig's Theorem
Let $\mathbf{y} \sim \mathcal{N}_n(\boldsymbol{\mu}, \sigma^2 \mathbf{I})$. Two quadratic forms $Q_1 = \mathbf{y}^T \mathbf{A} \mathbf{y}$ and $Q_2 = \mathbf{y}^T \mathbf{B} \mathbf{y}$ (where $\mathbf{A}, \mathbf{B}$ are real symmetric) are **statistically independent** if and only if:
$$\mathbf{A} \mathbf{B} = \mathbf{0}$$
:::

#### Proof that SSR and SSE are Independent:
Recall $\mathbf{A}_{\text{R}} = \mathbf{H} - \frac{1}{n}\mathbf{J}$ and $\mathbf{A}_{\text{E}} = \mathbf{I} - \mathbf{H}$. We compute their matrix product:
$$\mathbf{A}_{\text{R}} \mathbf{A}_{\text{E}} = \left(\mathbf{H} - \frac{1}{n}\mathbf{J}\right)(\mathbf{I} - \mathbf{H}) = \mathbf{H}(\mathbf{I} - \mathbf{H}) - \frac{1}{n}\mathbf{J}(\mathbf{I} - \mathbf{H})$$

1. Since $\mathbf{H}$ is idempotent ($\mathbf{H}^2 = \mathbf{H}$):
   $$\mathbf{H}(\mathbf{I} - \mathbf{H}) = \mathbf{H} - \mathbf{H}^2 = \mathbf{H} - \mathbf{H} = \mathbf{0}$$
2. For any regression model with an intercept, the column of ones $\mathbf{1}$ is in the column space of $\mathbf{X}$ ($\mathbf{X} = [\mathbf{1} \mid \mathbf{X}_1]$), meaning $\mathbf{H}\mathbf{1} = \mathbf{1}$. Because $\mathbf{J} = \mathbf{1}\mathbf{1}^T$:
   $$\mathbf{J}\mathbf{H} = (\mathbf{1}\mathbf{1}^T)\mathbf{H} = \mathbf{1}(\mathbf{H}\mathbf{1})^T = \mathbf{1}\mathbf{1}^T = \mathbf{J} \implies \mathbf{J}(\mathbf{I} - \mathbf{H}) = \mathbf{J} - \mathbf{J}\mathbf{H} = \mathbf{0}$$

Combining both parts:
$$\mathbf{A}_{\text{R}} \mathbf{A}_{\text{E}} = \mathbf{0} - \mathbf{0} = \mathbf{0}$$

By Craig's Theorem, **$\text{SSR}$ and $\text{SSE}$ are strictly independent random variables**. Consequently, the test statistic:
$$F^* = \frac{\text{SSR} / (p - 1)}{\text{SSE} / (n - p)} \sim F(p - 1, n - p)$$
is a ratio of independent chi-square variables, rigorously establishing the validity of the overall regression $F$-test.

## 6. Positive Definiteness, Gramian Matrices, and Cholesky Factorization

### 6.1 The Positive Definiteness of the Gram Matrix $\mathbf{X}^T \mathbf{X}$

In multiple regression, the cross-product matrix $\mathbf{X}^T \mathbf{X} \in \mathbb{R}^{p \times p}$ is the **Gram matrix** of the predictor column vectors.

::: {.callout-note}
### Theorem: Definiteness of $\mathbf{X}^T \mathbf{X}$
1. For any real matrix $\mathbf{X} \in \mathbb{R}^{n \times p}$, the Gram matrix $\mathbf{X}^T \mathbf{X}$ is **positive semidefinite** ($\mathbf{X}^T \mathbf{X} \succeq 0$).
2. If $\mathbf{X}$ has full column rank ($\operatorname{rank}(\mathbf{X}) = p \le n$), then $\mathbf{X}^T \mathbf{X}$ is **strictly positive definite** ($\mathbf{X}^T \mathbf{X} \succ 0$).
:::

#### Proof:
For any arbitrary non-zero vector $\mathbf{v} \in \mathbb{R}^p$, consider the quadratic form:
$$\mathbf{v}^T (\mathbf{X}^T \mathbf{X}) \mathbf{v} = (\mathbf{X}\mathbf{v})^T (\mathbf{X}\mathbf{v}) = \|\mathbf{X}\mathbf{v}\|_2^2 \ge 0$$
Since the Euclidean norm is non-negative, $\mathbf{X}^T \mathbf{X} \succeq 0$.

If $\operatorname{rank}(\mathbf{X}) = p$, the columns of $\mathbf{X}$ are linearly independent, meaning the null space contains only the zero vector:
$$\mathbf{X}\mathbf{v} = \mathbf{0} \iff \mathbf{v} = \mathbf{0}$$
Thus, for all $\mathbf{v} \neq \mathbf{0}$, $\|\mathbf{X}\mathbf{v}\|_2^2 > 0$. Hence $\mathbf{v}^T (\mathbf{X}^T \mathbf{X}) \mathbf{v} > 0$, establishing that $\mathbf{X}^T \mathbf{X}$ is **strictly positive definite** ($\mathbf{X}^T \mathbf{X} \succ 0$). $\blacksquare$

### 6.2 Numerical Solution of the Normal Equations via Cholesky Factorization

In computational statistics, explicitly inverting the $p \times p$ matrix $(\mathbf{X}^T \mathbf{X})^{-1}$ is strictly avoided because direct matrix inversion is numerically unstable and computationally inefficient.

Because $\mathbf{X}^T \mathbf{X} \succ 0$, it admits a unique **Cholesky decomposition**:
$$\mathbf{X}^T \mathbf{X} = \mathbf{L} \mathbf{L}^T$$
where $\mathbf{L} \in \mathbb{R}^{p \times p}$ is a lower triangular matrix with strictly positive diagonal elements ($L_{ii} > 0$).

The normal equations $\mathbf{X}^T \mathbf{X} \hat{\boldsymbol{\beta}} = \mathbf{X}^T \mathbf{y}$ are solved in two linear triangular stages:
1. **Forward Substitution**: Solve $\mathbf{L} \mathbf{z} = \mathbf{X}^T \mathbf{y}$ for $\mathbf{z} \in \mathbb{R}^p$ ($O(p^2)$ operations).
2. **Back Substitution**: Solve $\mathbf{L}^T \hat{\boldsymbol{\beta}} = \mathbf{z}$ for $\hat{\boldsymbol{\beta}} \in \mathbb{R}^p$ ($O(p^2)$ operations).

This reduces the computational cost to $\frac{1}{3} p^3$ operations—half the cost of general LU decomposition—with guaranteed numerical stability.

### 6.3 Spectral Properties of the Projection Hat Matrix $\mathbf{H}$

The hat matrix $\mathbf{H} = \mathbf{X}(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T \in \mathbb{R}^{n \times n}$ is an orthogonal projection operator onto the $p$-dimensional column space $\operatorname{Col}(\mathbf{X})$:

1. **Eigenvalues of $\mathbf{H}$**:
   Let $\lambda$ be an eigenvalue of $\mathbf{H}$ with eigenvector $\mathbf{v} \neq \mathbf{0}$:
   $$\mathbf{H}\mathbf{v} = \lambda \mathbf{v} \implies \mathbf{H}^2 \mathbf{v} = \lambda \mathbf{H}\mathbf{v} = \lambda^2 \mathbf{v}$$
   Since $\mathbf{H}^2 = \mathbf{H}$, we have $\lambda^2 \mathbf{v} = \lambda \mathbf{v} \implies \lambda(\lambda - 1)\mathbf{v} = \mathbf{0}$.
   Therefore, **all eigenvalues of $\mathbf{H}$ are strictly 0 or 1**:
   $$\lambda_i(\mathbf{H}) \in \{0, 1\}$$
2. **Multiplicity of Eigenvalues**:
   The sum of the eigenvalues equals the matrix trace:
   $$\sum_{i=1}^n \lambda_i = \operatorname{tr}(\mathbf{H}) = p$$
   Therefore, $\mathbf{H}$ has exactly **$p$ eigenvalues equal to 1** and **$n - p$ eigenvalues equal to 0**.
3. **Spectral Decomposition**:
   $$\mathbf{H} = \mathbf{Q} \begin{pmatrix} \mathbf{I}_p & \mathbf{0} \\ \mathbf{0} & \mathbf{0}_{n-p} \end{pmatrix} \mathbf{Q}^T = \sum_{i=1}^p \mathbf{q}_i \mathbf{q}_i^T$$
   where $\{\mathbf{q}_1, \dots, \mathbf{q}_p\}$ forms an orthonormal basis for $\operatorname{Col}(\mathbf{X})$.

## 7. Singular Value Decomposition (SVD) and Multicollinearity

The Singular Value Decomposition of the design matrix $\mathbf{X} \in \mathbb{R}^{n \times p}$:
$$\mathbf{X} = \mathbf{U} \boldsymbol{\Sigma} \mathbf{V}^T$$
provides deep insight into the stability of the normal equations:
- $\mathbf{U} \in \mathbb{R}^{n \times p}$ contains orthonormal basis vectors for $\operatorname{Col}(\mathbf{X})$.
- $\boldsymbol{\Sigma} = \operatorname{diag}(\sigma_1, \dots, \sigma_p)$ contains singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_p > 0$.
- $\mathbf{V} \in \mathbb{R}^{p \times p}$ is orthogonal.

The Gram matrix decomposes as:
$$\mathbf{X}^T \mathbf{X} = (\mathbf{V} \boldsymbol{\Sigma} \mathbf{U}^T)(\mathbf{U} \boldsymbol{\Sigma} \mathbf{V}^T) = \mathbf{V} \boldsymbol{\Sigma}^2 \mathbf{V}^T$$
and its inverse is:
$$(\mathbf{X}^T \mathbf{X})^{-1} = \mathbf{V} \boldsymbol{\Sigma}^{-2} \mathbf{V}^T = \sum_{j=1}^p \frac{1}{\sigma_j^2} \mathbf{v}_j \mathbf{v}_j^T$$

The **Condition Number** $\kappa(\mathbf{X}) = \frac{\sigma_1}{\sigma_p}$ governs numerical sensitivity. When severe multicollinearity exists, the smallest singular value $\sigma_p \approx 0$, causing $\frac{1}{\sigma_p^2} \to \infty$ and inflating the variance of $\hat{\boldsymbol{\beta}}$ along direction $\mathbf{v}_p$.

## 8. Computational Verification in Python

```python
import numpy as np
import scipy.linalg as la

# Generate synthetic linear model data: y = X beta + epsilon
np.random.seed(42)
n, p = 100, 4
X = np.hstack([np.ones((n, 1)), np.random.randn(n, p - 1)])
true_beta = np.array([2.5, -1.8, 3.2, 0.5])
sigma_noise = 1.2
y = X @ true_beta + np.random.normal(0, sigma_noise, size=n)

# 1. Cholesky Solution of Normal Equations
XtX = X.T @ X
Xty = X.T @ y
L = np.linalg.cholesky(XtX)
z = la.solve_triangular(L, Xty, lower=True)
beta_hat = la.solve_triangular(L.T, z, lower=False)
print("Estimated Coefficients (Cholesky):\n", beta_hat)

# 2. Hat Matrix and Idempotence
H = X @ np.linalg.inv(XtX) @ X.T
assert np.allclose(H @ H, H), "Hat matrix is not idempotent!"
assert np.allclose(H, H.T), "Hat matrix is not symmetric!"

# 3. Spectral Decomposition of Hat Matrix
eigvals_H = np.linalg.eigvalsh(H)
num_ones = np.sum(np.isclose(eigvals_H, 1.0))
num_zeros = np.sum(np.isclose(eigvals_H, 0.0))
print(f"Hat Matrix Eigenvalues: {num_ones} ones (rank p={p}), {num_zeros} zeros (rank n-p={n-p})")

# 4. Craig's Theorem Verification: A_R * A_E == 0
J = np.ones((n, n))
A_R = H - (1.0 / n) * J
A_E = np.eye(n) - H
craig_product = A_R @ A_E
assert np.allclose(craig_product, 0.0), "Craig's condition violated!"
print(f"Max absolute element of A_R @ A_E: {np.max(np.abs(craig_product)):.16e} (Identically zero)")
```
